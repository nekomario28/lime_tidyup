# AGENTS.md

This is a public project repository. Treat it as project-owned production/reference surface, not as a cross-project experiment host.

## Public-repository boundary

- Do not use this repository as the experimental foundation, scratch space, integration lab, or intermediate validation surface for another project.
- Cross-project experiments, exploratory integration, generated experiment artifacts, and temporary experiment workflows/branches belong in an explicitly private repository or private sandbox.
- This repository may be inspected read-only as current project truth or upstream/reference material.
- Results developed elsewhere may land here only as scoped, independently validated changes that belong to this project's own objective and preserve provenance.
- Do not keep temporary branches, workflows, fixtures, or artifacts here solely to support another project's experiment.

## Change discipline

Refresh current main before consequential writes. Keep changes bounded to this project's own purpose, preserve existing validation/authority boundaries, and never weaken a gate merely to make an external experiment pass.
